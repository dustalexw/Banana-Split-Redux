Banana Split Redux now runs on Windows 10 and 11 (64-bit), with every feature and the same look as the Mac app.

- **Everything comes along:** detection and review, the player, exact boundary re-encoding, black removal, validation, projects, two- and three-segment recommendations, Episode names with TMDB/TVDB lookup, and the command line.
- **Same style:** the charcoal, banana-yellow, pink and mint theme, with a charcoal title bar that runs into the brand bar on Windows 11 (dark title bar on Windows 10). Text uses Segoe UI.
- **Windows conventions:** Alt+Enter keeps a split and Alt+Backspace skips. Caches and logs live in `%LOCALAPPDATA%\BananaSplitRedux`. TMDB/TVDB keys are kept in Windows Credential Manager, and export work folders are hidden in Explorer.
- The Mac app is unchanged apart from the version.

## Install

**Windows:** run **Banana-Split-Redux-0.6.0-windows-x64-setup.exe**. It installs for you only and adds a Start-menu entry, an optional desktop icon, *Open with* for video files and an uninstaller. Or unzip **Banana-Split-Redux-0.6.0-windows-x64.zip** anywhere and run **Banana Split Redux.exe**. The app isn't code-signed, so if SmartScreen appears, choose **More info → Run anyway**.

**Mac:** download **Banana-Split-Redux-0.6.0-macos-arm64.zip**, unzip it, and double-click **Banana Split Redux.app** (Apple silicon, macOS 14 or later). The first time, right-click it and choose **Open**.

Python, Qt and FFmpeg are included in both. Checksums are in **Banana-Split-Redux-0.6.0-SHA256.txt**.

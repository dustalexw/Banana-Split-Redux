Banana Split Redux now splits two- and three-segment cartoons so every part matches one TVDB/TMDB episode, and names the parts `Show - S01E03 - Title`, numbered across the whole season.

- **Segments:** choose Auto, 1–6 beside Detection. Auto reads the file name: two episode numbers (`S01E01-E02`) or two segment titles mean two segments; otherwise it uses your usual count.
- **One recommended split per break:** halfway for two segments, about one third and two thirds for three, with more sensitive detection near each break. **Keep recommended** keeps them for one file; **Keep recommended splits in all** does every analysed episode. A break that already has a kept split never gets a second.
- **Episode names…:** numbers parts across the season from segment titles, file-name ranges or season order, skipping files that aren't in the queue. **Suggest names…** still works as before.
- **Optional TMDB or TVDB lookup** with your own key (**Keys…**, stored in your keychain): fills in titles, checks counts ("40 parts for 41 database episodes · missing E17") and can place breaks by segment runtimes. Only the show name is sent.
- Kept splits stay kept when you change the segment count or preset and when you reopen a project. Projects saved in 0.5.0 need 0.5.0 or later.

## Install

Download **Banana-Split-Redux-0.5.0-macos-arm64.zip**, unzip it, and double-click **Banana Split Redux.app**. The self-contained app runs on Apple-silicon Macs with macOS 14 or later; Python and FFmpeg are included. It is not notarized, so the first time, right-click it and choose **Open**. Checksums are in **Banana-Split-Redux-0.5.0-SHA256.txt**.
